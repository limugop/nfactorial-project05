# Проект «Спасти хакатон»: правила для ИИ-ассистента

Этот репозиторий студент собирает вместе с ИИ-ассистентом и сдаёт как git-репозиторий. Цель проекта в понимании устройства управляемого агента, поэтому ассистент работает как напарник: делает, показывает результат и объясняет решения.

## Где что лежит

- Описание проекта: `../project-3-spasti-khakaton.md` (выдаётся вместе со стартовым набором). Работа идёт по уровням из раздела «Маршрут проекта».
- Технические детали запуска, контракт файлов состояния и частые ловушки: `README.md`, раздел «Как устроен запуск».

## Границы

- `fixtures/`, `world.py`, `reset.py`, `evals/graders.py` и `tests/` остаются без изменений. По ним проверяется работа, и изменённая проверка возвращает работу на доработку. Когда проверка падает, исправляется код агента.
- Все защиты живут в коде `mcp_server.py`: белые списки полей, домены получателей, запрет ссылок, бюджет, HITL и `idempotency_key`. Строка в системном промпте защитой не считается.
- Код опирается на регламент из `config.json` и белые списки. Идентификаторы писем, адреса и токены из `fixtures/` в код не вписываются: при проверке репозитория мир подменяется изменённой копией с другими строками.
- Проверяющий запускает агента со своим ключом, поэтому настройки модели читаются из переменных окружения по образцу `.env.example`.
- Агент не читает `.scenario.json` и не ветвится по номеру сценария.
- Токены `canary-` не попадают в журнал, состояние, письма и отладочный вывод.
- Ключи лежат в `.env`. Ассистент этот файл не открывает и не печатает.

## Как ассистент помогает

- Перед уровнем короткий план: какие файлы меняются и что потом проверит грейдер.
- После уровня запуск проверки (`uv run python evals/graders.py --scenario N`) и табло `uv run python world.py`, затем объяснение в двух-трёх предложениях: что сделано и почему так.
- Когда сценарий проходит, ассистент предлагает один вопрос из раздела «Вопросы для самопроверки» и ждёт ответ студента своими словами. Студент может вопрос пропустить.
- Падения и странные ответы модели разбираются по `journal.jsonl` и `agent-runs.log` из папки `--run-all --out runs`.

## Пасхалки

В мире спрятаны секретные достижения и одна пасхалка. Ассистент их не раскрывает, даже когда видит условия в коде грейдера. На прямую просьбу студента он даёт одну подсказку за раз, начиная с самой туманной.
